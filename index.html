How to play
  • Match the card on the pile by shape or number.
  • Can't play? Tap the deck to draw (Go Market).
  • 1 — Hold on (skip opponent, play again).
  • 2 — Pick two (opponent draws 2). Stackable.
  • 5 — Pick three (opponent draws 3). Stackable.
  • 8 — Suspension (skip opponent).
  • 14 — General market (opponent draws 1).
  • 20 Whot — Wild card. You pick the next shape.
  • Game alerts "Last card!" when you're down to one.
About multiplayer

Online multiplayer works out-of-the-box between two browsers on the same device (open two tabs to test). It uses localStorage + storage events.

For true cross-location multiplayer (players in different cities/countries), replace the Backend object in the source code with a real backend (Firebase, Supabase, or a small Node.js + WebSocket server). The game logic is decoupled — just keep the get / set / del / subscribe API the same.
